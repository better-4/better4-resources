# better4-resources

Collection of resources that may be helpful for [Better4](https://github.com/better-4/Better4) development.

* `assets/`: non-plaintext files (skeletons, animations, etc.)
* `docs/`: plaintext documentation
* `templates/`: 010 editor binary templates (courtesy of [GHSDK](https://gitgud.io/fretworks/guitar-hero-sdk))
* `tools/`: various tools used for converting skeletons/animations/etc.
