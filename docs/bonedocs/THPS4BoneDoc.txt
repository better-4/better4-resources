For using the weight transfer blend on models not in x-pose you need to line the imported model up with the CAS one as best as you can
then rotate the legs on the Z-axis (by .2 left and -.2 right) transfer the weights like normal, then before making the skeleton the parent to the imported model
you need to apply the pose as rest pose, then carry on (the original CAS will lose transformations but it shouldnt be needed anymore anyways) 
then before exporting, pose the model back to how it was before (dont apply it as rest this time)
export and use yoshi's tool
